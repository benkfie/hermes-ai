# Hermes AI — VS Code Extension

## Project
- **Name**: hermes-ai
- **Repo**: https://github.com/benkfie/hermes-ai.git
- **Fork of**: joaompfp/hermes-vscode (v3.0.0)
- **Description**: VS Code extension for Hermes AI agent over ACP protocol

## Conventions
- TypeScript codebase, webpack build
- Conventional commits: feat, fix, refactor, chore, docs, test, perf
- Main entry: src/extension.ts
- Build output: dist/extension.js

## Key Files
- src/extension.ts — activation entry point
- src/acpClient.ts — ACP JSON-RPC client
- src/sessionManager.ts — ACP session management
- src/chatPanel.ts — Chat webview provider
- src/settingsPanel.ts — Settings webview provider (NEW)
- config/ — Config management backend (NEW)
- webview/ — Chat and settings webview UIs
